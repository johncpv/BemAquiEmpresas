## Para que serve
Definir como cada tipo de documento é numerado (orçamento, contrato, ordem de serviço, pedido de compra e os demais), por exemplo ORC-2026-0001.

## Como usar
- A tabela mostra, para cada tipo, o prefixo, se a numeração reinicia por ano, quantos dígitos tem, o último número emitido e o próximo.
- Clique no nome do tipo para abrir o painel. A linha **Próximo** mostra, enquanto você digita, como sairá o próximo número.
- Clique em **Salvar numeração** e confirme. A mudança vale do próximo número em diante. Os números já emitidos não mudam.
- Use **Próximo número** para continuar a numeração do sistema antigo. Ele só pode aumentar.

## Perguntas frequentes
**Por que não consigo mudar "Reinicia por ano"?** Depois do primeiro número emitido, o reinício anual fica travado, para não gerar número repetido.

**Posso voltar a numeração para um número menor?** Não. O próximo número precisa ser maior que o último emitido, para nunca repetir.

**Dois tipos podem ter o mesmo prefixo?** Não. Cada tipo tem o seu, para que o número diga de que documento se trata.

**Quais caracteres o prefixo aceita?** De 1 a 6 letras sem acento ou números, sem espaço.
