## Para que serve
Ver o que foi vendido no projeto de serviço: a descrição e a quantidade de cada item.

## Como usar
- Os itens vêm do orçamento aprovado. O projeto de serviço não tem OS de fabricação, romaneio nem OS de instalação.
- Para incluir ou tirar item, use um **Aditivo** do contrato.

## Perguntas frequentes
**Por que não aparece "Gerar OS"?** Serviço não passa pela fábrica: o andamento é pelo próximo passo no cabeçalho (iniciar, entrega e aceite do cliente).
