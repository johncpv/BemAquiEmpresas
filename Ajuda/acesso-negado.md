## Para que serve
Avisa que o módulo está liberado para a empresa, mas nenhum dos seus grupos dá acesso a ele.

## Como usar
- Peça a quem administra os acessos para incluir você num grupo com permissão para o módulo.
- Depois que o grupo for ajustado, a tela libera no próximo clique, sem precisar sair do sistema.

## Perguntas frequentes
**Por que o módulo não aparece no meu menu?** O menu só mostra o que você pode usar. Os módulos com cadeado ainda não foram liberados para a empresa.
